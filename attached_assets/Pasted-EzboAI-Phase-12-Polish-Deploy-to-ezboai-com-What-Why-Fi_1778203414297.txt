Steps
Branding assets — final logo via media-generation skill or user-supplied; place in artifacts/web-app/public/. Generate favicons via online tool or sharp script.
Replace placeholders — search codebase for "TODO", "Coming soon", "Phase X", "placeholder" — handle each.
Onboarding modal — components/OnboardingModal.tsx; show on first visit (localStorage flag).
Loading/error pass — every page: add Suspense skeletons + error boundaries.
Bangla copy proofread — go through every UI string; ensure natural phrasing.
Performance audit —
Run vite build --mode production; check bundle size
Add React.lazy for heavy pages (Admin, Automations, Files)
Compress images, use AVIF/WebP where possible
Run Lighthouse in DevTools; address top suggestions
Accessibility audit — keyboard-test every flow; run axe DevTools; fix violations.
SEO — meta tags, robots.txt, sitemap, JSON-LD.
Help page — pages/Help.tsx with FAQ, troubleshooting, link to GitHub/contact.
Update replit.md — final state.
Pre-deploy checklist:
All env vars set (DATABASE_URL, ADMIN_PASSWORD, APP_ENCRYPTION_KEY, SESSION_SECRET, VAPID keys)
At least one provider key added in admin (so chat works for testing)
Routing rules sane defaults
DB migrations applied
Deploy — read deployment skill, choose Reserved VM (needed for: long-running scheduler, Playwright, websockets), set env vars in deployment settings.
Custom domain —
In Replit deployment settings → Add domain → ezboai.com
Replit shows DNS records (A or CNAME) needed
User adds them at their registrar (provide step-by-step instructions in Bangla in chat)
Wait for verification + SSL
Production smoke test — manually walk through every feature on ezboai.com; fix any production-only issues.
Monitoring — set up basic uptime monitoring (e.g. Replit's built-in or external like UptimeRobot).
Hand off to user — confirm deployment is live, give admin password reminder, link to admin panel, suggest first AI keys to add.
Suggest deploy — call suggest_deploy if not already deployed.
Critical constraints
Reserved VM, NOT Autoscale — Autoscale would kill long-running browser sessions and the cron scheduler.
All secrets must be set in deployment env, not just dev env.
Custom domain DNS propagation can take up to 48 hrs — set expectations.
Database migrations: ensure prod DB schema matches by running drizzle-kit push against prod.
Don't lose user's API keys during deploy: the encrypted keys live in prod DB, so make sure dev → prod doesn't reset DB.
